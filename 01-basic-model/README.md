# 01 基础模型

本目录用于存放 FLAC3D 数值模拟的基础案例，从最简单的三维岩体模型开始，逐步掌握建模、网格划分、材料赋值、边界条件设置和计算求解。

## 案例列表

| 编号 | 案例名称 | 主要内容 |
|---|---|---|
| 01 | 三维基础模型 | 建立简单的三维模型 |
| 02 | 网格划分 | 学习模型网格的生成与控制 |
| 03 | 材料参数赋值 | 设置岩体物理力学参数 |
| 04 | 边界条件设置 | 设置模型边界约束 |
| 05 | 初始应力平衡 | 建立初始应力并进行平衡计算 |

## 案例文件规范

每个案例应尽可能包含：

- `README.md`：案例目的、参数说明和运行步骤。
- `model.dat`：FLAC3D 计算命令。
- `results/`：计算结果与可视化图片（如有）。

## 学习顺序

几何建模 → 网格划分 → 材料赋值 → 边界条件 → 初始应力平衡。

**说明：** 本目录中的案例将逐步补充，并注明适用的软件版本。未经验证的模型不作为工程设计依据。
