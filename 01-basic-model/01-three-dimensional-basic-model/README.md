# 案例 01：三维基础模型

## 1. 案例目的

本案例使用 FLAC3D 建立一个规则的三维长方体计算模型，作为后续巷道开挖、围岩支护、应力分析和采矿模拟的基础。

本案例的学习目标包括：

1. 理解 FLAC3D 三维数值模型的基本组成。
2. 掌握规则长方体模型的几何定义方法。
3. 理解网格数量、模型尺寸与单元尺寸之间的关系。
4. 学习模型分组的基本概念。
5. 建立规范的模型文件和案例说明文档。

**本案例只建立几何模型和网格，不进行材料赋值、边界约束、初始应力计算或力学求解。**

## 2. 工程背景

在煤矿巷道围岩稳定性分析中，通常需要先建立包含巷道及周围岩体的三维计算区域，再根据研究目标逐步设置岩体力学参数、边界条件、初始应力和开挖过程。

本案例暂不考虑实际矿井中的断层、节理、层理、地下水及复杂地质结构，而是使用规则长方体作为基础模型。

这种简化模型用于学习软件操作和数值建模流程，不代表实际矿井的工程计算结果。

## 3. 模型设计参数

| 参数名称 | 符号 | 设定值 |
|---|---|---:|
| X 方向长度 | Lx | 20 m |
| Y 方向宽度 | Ly | 12 m |
| Z 方向高度 | Lz | 16 m |
| X 方向网格数量 | Nx | 10 |
| Y 方向网格数量 | Ny | 6 |
| Z 方向网格数量 | Nz | 8 |
| 网格单元总数 | N | 480 |
| X 方向单元尺寸 | Δx | 2 m |
| Y 方向单元尺寸 | Δy | 2 m |
| Z 方向单元尺寸 | Δz | 2 m |

以上参数均为教学用设定值，长度单位统一采用米（m）。

## 4. 三维坐标系

本案例采用三维直角坐标系。

- X 方向：模型长度方向，坐标范围为 0～20 m。
- Y 方向：模型宽度方向，坐标范围为 0～12 m。
- Z 方向：模型高度方向，坐标范围为 0～16 m。
- 坐标原点：模型底部的一个角点，即 (0, 0, 0)。

模型通过四个参考点定义空间位置和尺寸：

| 参考点 | X 坐标 | Y 坐标 | Z 坐标 |
|---|---:|---:|---:|
| Point 0 | 0 | 0 | 0 |
| Point 1 | 20 | 0 | 0 |
| Point 2 | 0 | 12 | 0 |
| Point 3 | 0 | 0 | 16 |

其中，Point 1 确定 X 方向，Point 2 确定 Y 方向，Point 3 确定 Z 方向。实际建模时还需要保证坐标定义符合软件的几何要求。

## 5. 网格划分原理

本案例采用规则六面体网格。

### 5.1 网格总数

网格单元总数的计算公式为：

N = Nx × Ny × Nz

代入本案例参数：

N = 10 × 6 × 8 = 480

因此，模型理论上包含 480 个网格单元。

### 5.2 单元尺寸

X 方向单元尺寸：

Δx = Lx / Nx = 20 / 10 = 2 m

Y 方向单元尺寸：

Δy = Ly / Ny = 12 / 6 = 2 m

Z 方向单元尺寸：

Δz = Lz / Nz = 16 / 8 = 2 m

三个方向的单元尺寸均为 2 m，因此本案例生成的是规则、等尺寸的网格。

需要注意：网格单元数量不等于网格节点数量。

## 6. 模型分组

本案例将生成的网格单元统一划入 `rock` 分组。

分组的作用是对模型中的区域进行分类，便于后续对不同岩层、开挖区域、支护区域或其他计算区域进行选择和管理。

**重要说明：** `rock` 只是分组标签，不代表已经为网格赋予了岩石的本构模型或物理力学参数。

材料参数将在后续案例中单独设置。

## 7. 文件结构

本案例采用以下文件结构：

```text
01-three-dimensional-basic-model/
├── README.md
└── model.dat
```

文件说明：

- `README.md`：记录案例目的、模型参数、计算原理、运行方法和验收标准。
- `model.dat`：存放 FLAC3D 模型创建命令。

说明文档与计算代码分开存放，便于后续维护、检查和复现。

## 8. 运行流程

1. 打开 FLAC3D 软件。
2. 使用独立工作会话，或确认当前模型已经保存。
3. 打开本案例的 `model.dat` 文件。
4. 执行模型创建命令。
5. 在模型显示窗口中检查三维长方体及网格。
6. 核对三个方向的尺寸和网格数量。
7. 确认模型状态已保存。

具体命令语法应与实际安装的 FLAC3D 版本保持一致。

注意：如果脚本中使用 `model new`，该命令会重置当前模型状态。执行前应确认其他模型已经保存。

## 9. 结果检查与验收标准

模型生成后，应逐项检查：

- [ ] 三维长方体模型能够正常生成。
- [ ] X 方向长度为 20 m。
- [ ] Y 方向宽度为 12 m。
- [ ] Z 方向高度为 16 m。
- [ ] X、Y、Z 方向网格数量分别为 10、6、8。
- [ ] 理论网格单元总数为 480。
- [ ] 网格单元具有 `rock` 分组标签。
- [ ] 计算文件没有语法错误。
- [ ] 模型尚未进行力学求解，不将几何模型误认为应力分析结果。

上述检查结果应以实际运行的 FLAC3D 模型为准，不能仅凭代码文本判断运行成功。

## 10. 常见问题

### 10.1 模型无法生成

检查数据文件中的命令是否完整，以及命令语法是否与当前 FLAC3D 版本兼容。

### 10.2 模型尺寸不正确

检查参考点坐标和各方向的定义是否正确。

### 10.3 网格数量不正确

检查三个方向的网格数量，并重新计算：

N = Nx × Ny × Nz

### 10.4 为什么没有应力云图？

本案例仅建立几何和网格，尚未设置材料参数、边界条件和初始应力，也没有进行力学求解，因此不应产生可用于工程分析的应力结果。
